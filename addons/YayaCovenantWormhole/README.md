# Yaya Covenant Wormhole

Mini addon Retail pour le `Wormhole Generator: Shadowlands`.

Ce qu'il fait :

- detecte ton covenant actif
- choisit automatiquement la zone associee dans le gossip du wormhole
- bypass manuel avec `Shift` maintenu
- logs de debug actifs par defaut dans le chat

Commandes :

- `/ycw`
- `/ycw debug`
- `/ycw on`
- `/ycw off`
- `/ycw test`

Mapping :

- Kyrian -> `Bastion`
- Venthyr -> `Revendreth`
- Night Fae -> `Ardenweald`
- Necrolord -> `Maldraxxus`
