# YayaProfessionSpecializations

Addon minimal qui dump les arbres de specialisation des metiers dans `YayaProfessionSpecializationsDB`.

Commandes:

- `/yayaspec`
- `/yayaspec dump`
- `/yayaspec show`

Le scan se lance aussi automatiquement:

- au login
- quand les lignes de metier changent
- quand la fenetre de metier s'ouvre
