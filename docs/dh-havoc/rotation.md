# Openers et priorités

Le **hero talent doit être identifié avant de juger un ordre de casts**. `Chaos Strike` avant `Blade Dance` n’est pas une règle universelle : c’est surtout une optimisation Aldrachi pendant certains buffs de funnel.

## Fel-Scarred — mono-cible

```text
Immolation Aura pré-pull → potion/trinket → Eye Beam → The Hunt
→ Essence Break → Annihilation → Death Sweep ×2
→ Vengeful Retreat + Metamorphosis
→ Death Sweep → Annihilation → Consuming Fire → Abyssal Gaze
→ Death Sweep ×2 → Annihilation
```

Pourquoi : `Eye Beam` ouvre Demonic, `Essence Break` doit être suivi de spenders, les premiers Death Sweep/Annihilation consomment les premiers procs, puis Meta fournit les resets pour la seconde moitié. On évite de lancer Meta en premier si cela gaspille les resets ou les charges d’Aura.

## Fel-Scarred — AoE / M+

```text
Vider les charges d’Immolation Aura → potion/trinket
→ The Hunt / Eye Beam → Essence Break
→ Death Sweep ×2 → Annihilation
→ Vengeful Retreat + Metamorphosis
→ Death Sweep → Annihilation → Consuming Fire
→ Eye Beam/Abyssal Gaze → Death Sweep ×2 → Annihilation
```

Sur un pack court, consommer la première fenêtre vaut mieux que conserver Meta pour une seconde phase qui n’existera pas. Sur un gros pack, préparer `Burning Wound` sur trois cibles et protéger l’explosion `Ragefire`.

## Aldrachi Reaver — mono-cible

```text
Immolation Aura → The Hunt → potion/trinket → Reaver’s Glaive
→ Eye Beam → Essence Break → Death Sweep → Annihilation → Death Sweep
→ Vengeful Retreat + Metamorphosis → Death Sweep → Eye Beam
→ Annihilation → Death Sweep ×2
```

`Reaver’s Glaive` prépare les buffs ; l’ordre des deux spenders dépend de l’objectif. En mono sans buff spécial, `Death Sweep` reste prioritaire avant `Annihilation`.

## Aldrachi Reaver — cleave/funnel

- `Reaver’s Glaive` sur la cible prioritaire.
- `Reaver’s Mark` actif.
- `Blade Dance` avant `Chaos Strike` si seul `Glaive Flurry` est actif.
- `Chaos Strike/Annihilation` avant `Blade Dance/Death Sweep` si `Glaive Flurry` **et** `Rending Strike` sont actifs.
- Le surplus de dégâts physiques sur les autres cibles revient à la cible marquée via `Wounded Quarry`.

## Priorités qui expliquent les boutons

1. Ne pas caper Fury ; garder assez de Fury pour le spender prioritaire.
2. Utiliser `Essence Break` régulièrement, puis placer les spenders dans sa fenêtre.
3. Finir `Eye Beam` si la cible reste en portée : un canal interrompu perd le buff associé.
4. Consommer les procs `Demonsurge` avec `Death Sweep`/`Annihilation`.
5. Utiliser `Immolation Aura` avant deux charges ; en Fel-Scarred, vider les charges avant Meta pour profiter du reset.
6. Garder `The Hunt` pour la fenêtre prévue, mais ne pas perdre une utilisation pour une superposition théorique.
7. `Ragefire` doit exploser près des cibles ; ne pas faire `Fel Rush`/`Vengeful Retreat` juste avant si cela vide la zone.

## Contrôles WCL

Pour une fenêtre donnée, vérifier :

- timestamps de `The Hunt`, `Eye Beam`, `Essence Break`, `Metamorphosis`, `Death Sweep`, `Annihilation` ;
- buffs actifs au moment du spender ;
- procs Demonsurge/Reaver’s Glaive consommés ou expirés ;
- durée du debuff Essence Break et nombre de spenders dedans ;
- cibles réellement touchées par Aura, Ragefire et Burning Wound ;
- uptime, déplacements, morts et temps après résurrection.
